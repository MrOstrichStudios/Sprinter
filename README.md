## How to PLAY?
simply get the zip from the Releases (currently **v1.1-alpha**), extract the zip, then run Sprinter.exe then play!
## Controls:
- WASD/Arrows Keys : Move
- Mouse : Look
- Space : Jump
- Left Shift : Sprint
- Left Ctrl : Slide
- LMB : Grapple
- RMB : Swing
- R : Reset Level
- Alt + F4 : Quit
