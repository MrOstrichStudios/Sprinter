## How to PLAY?
simply get the zip from the Releases (currently **v1.3-alpha**), extract the zip, then run Sprinter.exe then play!
## Controls:
- WASD/Arrows Keys : Move
- Mouse : Look
- Space : Jump
- Left Shift : Sprint
- Left Ctrl : Slide
- LMB : Grapple
- RMB : Swing
- R : Retry Level (After Death Only)
- Q : Retry from Last Checkpoint (After Death Only)
- Alt + F4 : Quit
